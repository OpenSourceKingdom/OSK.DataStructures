# OSK.DataStructures
A library of common and helpful data structures like two way maps, and others, as they are added. Currently included data structures:
- `IBiMap`: Two-way map binding between data types. This is a forward/reverse lookup of data that can be useful when standard key only style lookup is not enough
- `ICollectionNavigator`: A navigator of a collection, useful carousel and moving within a data collection.

# Usage
Add the package to your project and use the needed data structures as necessary.
